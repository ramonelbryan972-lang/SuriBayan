# SuriBayan 🇵🇭

**Magtanong. Magsuri. Matuto.** A free, mobile-friendly, nonpartisan Filipino civic-literacy website designed to make government, public budgets, corruption, due process and media literacy understandable to Grades 5–6 and families.

## Features

- Eight short Filipino/Taglish civic lessons with examples and quick-check questions
- Three sourced Philippine case summaries with clearly labeled status (court ruling, investigation, policy)
- Fictional school-project story that teaches verification and responsible questions
- Interactive **₱100 community budget simulation** (not real government budget data)
- Five-round SURI misinformation-literacy lab
- Twelve-question civic quiz with explanations
- Reading progress saved locally in the browser (no sign-in, analytics, or data collection)
- No external JavaScript, CSS dependencies, APIs, or build tools

## Publish on GitHub Pages

1. Create a new public GitHub repository such as `suribayan`.
2. Upload `index.html`, `styles.css`, `app.js`, `README.md`, `LICENSE`, and `CONTRIBUTING.md` to the repository root.
3. Open **Settings → Pages → Deploy from a branch → main → / (root)** and save.
4. The site should be available at `https://YOUR-USERNAME.github.io/suribayan/` after deployment.

To run locally, open `index.html` in your browser. The single-file offline version is provided separately.

## Editorial standards

- Educational and **nonpartisan**: no political candidate or party endorsements.
- **Allegation ≠ proven fact.** Ongoing investigations are labeled as such; a COA observation is not automatically proof of theft.
- The budget lab and school story are prominently labeled as **fictional simulations**.
- Real-world current-events summaries are dated **November 19, 2026** and are **not live feeds**. Verify updates with source links before using the content as current news.
- Use respectful language. Do not dox, harass, or invite minors to investigate potentially unsafe situations.
- Personal progress is local to the browser and can be reset. Nothing is uploaded to a server.

## Local development

No installation needed. Edit the HTML, CSS, and vanilla JavaScript. If you improve the site, review claims against primary sources before publishing. Submit changes by pull request.

This is a community educational project, not an official Philippine government website, fact-checking agency, news outlet, or substitute for legal advice.
